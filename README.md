# 게임 한글화 Skill
한글화 패치를 제작하기 위한 AI Skill을 모아둔 저장소입니다.  
현재 모든 Skill은 Open AI Codex를 기반으로 작업하고 있습니다.  
각 폴더 및 다운로드 zip 파일은 아래와 같습니다.
- **Korean2350** : 완성형 한글 2350자 텍스트 데이터
- **game-analyzer-for-localization-kr** : 한글화 패치 작업을 위한 분석 및 계획 수립 
- **game-localize-unity4-tk2d** : 유니티4 + 2D Toolkit 기반 게임 타겟으로 하는 구체적인 한글화 작업
