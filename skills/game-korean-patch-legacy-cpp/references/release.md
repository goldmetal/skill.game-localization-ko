# 버전 이식과 배포

## 기준선과 백업

재구현 엔진의 버전, 실행 파일 해시, OS·아키텍처, 소스 태그·커밋과 원작 데이터 경로를 기록한다. 설치된 문서·실행 파일 식별 정보·CMake 프로젝트 버전을 대조해 대응하는 공식 소스를 사용한다. 다른 버전의 최신 브랜치를 임의로 대체하지 않는다.

작업 공간을 소스, 빌드, 격리 실행 자산, 배포용 staging으로 구분한다. 절대 경로와 사용 도구 버전은 해당 작업의 보고서에 기록하며 스킬 자체에 고정하지 않는다.

교체할 파일 목록을 먼저 확정하고 기존 파일과 SHA-256을 백업한다. 이전 소스·배포본의 사용자 변경을 보존한다. 같은 이름의 백업이 있으면 덮어쓰지 말고 버전 또는 작업 시각으로 구분한다. 백업 당시 없었던 새 파일도 기록해 원복 시 구분한다.

## 기존 패치를 새 버전에 이식

1. 기존 패치에서 번역, 문자열 표현, 글꼴, UI, 저장 호환 보정을 구분한다.
2. 새 버전의 해당 경로 변경과 새 문자열·오브젝트 범위만 비교한다.
   - 표시 제어 코드의 예약 상태, YAML 로더·인수 명령, G1 폭 계산, 창의 상대 좌표·위젯·툴바 통합 변경을 우선 확인한다.
3. 새 공식 기준에 변경을 이식한다. 패치 충돌과 거부된 hunk를 명시적으로 해결한다.
4. 인코딩·개행 설정으로 전체 파일이 바뀐 것처럼 보이는지 확인한다. 의미 있는 최소 diff로 정리한다.
5. 현재 빌드의 자산·언어·폰트를 사용한다. 이전 배포본의 리소스를 재사용할 때 버전 호환성을 확인한다.
6. 최종 소스 패치를 깨끗한 기준 소스에 재적용하고 수정 파일 내용을 대조한다. 바이너리 글꼴 등 별도 자산의 재현 절차도 남긴다.

## 빌드와 설치

현재 소스의 CMake preset과 Windows MSVC·SDK·vcpkg를 우선 사용한다. SDL·yaml-cpp·이미지·오디오·포맷·테스트 라이브러리 등 의존성은 해당 소스가 요구하는 기준을 따른다. 이전 빌드 캐시·라이브러리는 기준과 아키텍처가 같은 경우에만 재사용하고, 번역·오브젝트 자산은 새 엔진 버전과 맞춘다.

동적 글꼴 공급자 소스·헤더·필요 시스템 라이브러리를 CMake 대상에 포함한다. 테스트에도 글꼴 자산과 실제 출력 경로가 연결되어야 한다. 정적·동적 연결 방식을 기록하고 필요한 런타임 파일만 포함한다. 배포 실행 파일이 실제 기준 버전을 표시하는지 확인하며 아카이브 소스 빌드에서 커밋 정보가 없으면 허위 정보를 만들지 않는다.

실제 설치 파일은 백업 완료와 검증 결과를 확인한 뒤 사용자 요청 범위에서 적용한다. 기존 세션이 설치 적용까지 허용했다면 재확인을 반복하지 않는다. 파일 잠금·권한·무결성 제약은 우회하지 말고 독립 작업을 완료한 상태에서 필요한 조치만 요청한다.

다른 실행 파일이 패치 사본처럼 보이더라도 이름만으로 교체하지 않는다. 실제 해시·런처 연결·기존 설치 방식을 확인한다. 확인되지 않은 스토어 실행 파일이나 원작 실행 파일은 교체 대상으로 확대하지 않는다.

## 배포물 검증

- 배포용 staging은 필요한 파일을 명시한 목록으로 구성한다. 로컬 설정·로그·세이브·비밀값·원작 자산·빌드 캐시를 우연히 포함하지 않는다.
- 기본 배포 구성은 수정 실행 파일, 한국어 YAML, 동적 글꼴과 라이선스다. 별도 실행 폴더가 자체 언어·오브젝트 자산을 읽는다면 현재 버전의 해당 자산도 함께 준비하되 원작 DAT를 재배포하지 않는다.
- 글꼴·소스·런타임의 수정·재배포 조건에 맞는 고지를 함께 제공한다.
- 설치 대상 버전, 적용 방법, 언어 선택 방법, 원복 절차와 알려진 제한을 제공한다.
- staging, 설치본, 압축 파일 내부의 필수 파일 해시와 파일 목록을 대조한다. ZIP 생성 성공을 내용 검증으로 대신하지 않는다.
- 공개 업로드·출시·다른 사람에게 전송은 사용자가 요청한 경우에만 수행한다. 로컬 배포 ZIP 제작은 공개 게시가 아니다.

복원 스크립트가 있다면 실행 중인 게임, 백업 해시, 허용된 상대 경로와 설치 루트를 검사한다. 검증되지 않은 계산 경로에 재귀 삭제·이동을 수행하지 않는다. 테스트 목적으로 실제 세이브를 지우거나 사용자 설정 전체를 초기화하지 않는다.
